# Form Builder

Build forms by dragging and dropping components.

## How to Use

1. **Drag components** from the left panel to the form area
2. **Click a component** to edit its properties in the right panel
3. **Drag within form** to reorder components
4. **Click × button** to delete a component
5. **Click "Copy Code"** to get the complete form code
