# Component Library Release Notes

Track what was added, changed, fixed, removed, and deprecated in each deployment.

**Version:** `1.0`  
**Released:** `2026-07-21`  
**Focus:** Component updates and improvements.

## Highlights

### Added
- [Page Details](?path=/docs/design-system-components-layout-and-navigation-page-details--docs): Added new property `imageStyles` for enhanced customization.
- [Custom Dropdown Modal](?path=/docs/design-system-components-custom-dropdown-modal--docs): Added new property `isClosemodalForcefully` for enhanced customization.
- [Calender](?path=/docs/design-system-components-form-controls-bfl-calendar--docs): Added new property `styles` for enhanced customization; Added new properties `prevIconUrl`, `nextIconUrl` for enhanced customization.

### Changed
- [Accordian](?path=/docs/design-system-components-data-display-accordion--docs): Updated Storybook documentation with improved examples and usage guidelines.
- [Note Input](?path=/docs/design-system-components-data-display-note-card--docs): Updated Storybook documentation with improved examples and usage guidelines.
- [Page Details](?path=/docs/design-system-components-layout-and-navigation-page-details--docs): Updated Storybook documentation with improved examples and usage guidelines.
- [Strip Popup](?path=/docs/design-system-components-micro-interaction-strip-popup--docs): Updated Storybook documentation with improved examples and usage guidelines.
- [Calender](?path=/docs/design-system-components-form-controls-bfl-calendar--docs): Improved visual styling and UI consistency. (CSS styling updated)

### Fixed
- [Cta Link](?path=/docs/design-system-components-layout-and-navigation-cta-link--docs): Bug fixes and stability improvements.
- [Strip Popup](?path=/docs/design-system-components-micro-interaction-strip-popup--docs): Bug fixes and stability improvements; Fixed positioning and floating behavior.
