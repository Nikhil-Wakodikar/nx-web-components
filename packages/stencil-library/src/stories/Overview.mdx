# NX Web Components

Reusable, accessible web components built with Stencil and designed for framework-independent use.

## Components

- `nx-button`: button variants and actions
- `nx-input`: labeled text input with validation states
- `nx-checkbox`: single boolean selection
- `nx-radio-group` and `nx-radio`: mutually exclusive selection
- `nx-grid`, `nx-row`, and `nx-col`: responsive layout primitives

## Design Tokens

The global stylesheet exposes the `--nx-*` color, typography, spacing, radius, shadow, and layering tokens. Import `stencil-library/styles.css` once in the consuming application's global stylesheet.
