# NX Web Components — Angular Integration Guide

A modern enterprise UI component library built with [Stencil](https://stenciljs.com) featuring first-class **Angular (v16+)** support. 

Includes typed standalone Angular component wrappers, automatic `ControlValueAccessor` integration for Reactive Forms and `ngModel`, built-in form validation sync, programmatic dialog/modal services, and customizable design tokens.

🔗 **Storybook Live Documentation**: [https://nikhil-wakodikar.github.io/nx-web-components/?path=/docs/nx-web-components-overview--docs](https://nikhil-wakodikar.github.io/nx-web-components/?path=/docs/nx-web-components-overview--docs)

---

## 📦 1. Installation

Install the library with a single npm command:

```bash
npm install @_nx/stencil-library
```

> **Note**: Both the core Web Components and the Angular Ivy integration layer (`@_nx/stencil-library/angular`) are bundled in this single package. No separate wrapper package is needed.

---

## 🎨 2. Global Styles & Typography

Import the global design system stylesheet into your Angular application's global stylesheet (`src/styles.scss`):

```scss
@import "@_nx/stencil-library/styles.css";

// Optional: Customize theme tokens and root font family
:root {
  --nx-font-family-base: 'Poppins', sans-serif;
  --nx-color-primary: #8145b5;
  --nx-color-primary-hover: #6e389c;
  --nx-radius-md: 0.5rem;
}

body {
  font-family: var(--nx-font-family-base);
}
```

## 🚀 3. Application Setup

### Standalone Angular Applications (Recommended)

In your `src/main.ts`, register the custom element loader using `provideNxWebComponents()`:

```typescript
import { bootstrapApplication } from '@angular/platform-browser';
import { provideNxWebComponents } from '@_nx/stencil-library/angular';
import { AppComponent } from './app/app.component';

bootstrapApplication(AppComponent, {
  providers: [
    provideNxWebComponents(),
    // other application providers
  ]
}).catch(err => console.error(err));
```

### NgModule Applications

If your application uses traditional `NgModule`, import `NxComponentLibraryModule` (which exports all component proxies, value accessors, and directives):

```typescript
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { FormsModule, ReactiveFormsModule } from '@angular/forms';
import { NxComponentLibraryModule } from '@_nx/stencil-library/angular';
import { AppComponent } from './app/app.component';

@NgModule({
  declarations: [AppComponent],
  imports: [
    BrowserModule,
    FormsModule,
    ReactiveFormsModule,
    NxComponentLibraryModule
  ],
  bootstrap: [AppComponent]
})
export class AppModule {}
```

## 🧩 4. Standalone Component Usage

All component wrappers are Angular standalone components and can be imported directly where needed:

```typescript
import { Component } from '@angular/core';
import { NxButton, NxBadge, NxCard } from '@_nx/stencil-library/angular';

@Component({
  selector: 'app-dashboard',
  standalone: true,
  imports: [NxButton, NxBadge, NxCard],
  template: `
    <nx-card variant="elevated" padding="medium" headerTitle="Dashboard" subtitle="Account overview">
      <p>
        Status: <nx-badge color="success" variant="subtle">Active</nx-badge>
      </p>
      <p>Manage your account settings and preferences.</p>

      <!-- Native (click) event works directly -->
      <div slot="footer">
        <nx-button color="primary" fill="solid" (click)="onSave()">
          Save Changes
        </nx-button>
      </div>
    </nx-card>
  `
})
export class DashboardComponent {
  onSave() {
    console.log('Button clicked!');
  }
}
```

## 📝 5. Reactive Forms & ngModel Integration

All form components (`nx-input`, `nx-checkbox`, `nx-radio`, `nx-radio-group`, `nx-select`, `nx-textarea`, `nx-toggle`, `nx-autocomplete`, `nx-date-picker`, `nx-time-picker`) have built-in `ControlValueAccessor` directives (`TextValueAccessor`, `BooleanValueAccessor`, `RadioValueAccessor`, or `NX_VALUE_ACCESSORS`) that automatically sync Angular form states (`touched`, `dirty`, `invalid`, `disabled`):

```typescript
import { Component, inject } from '@angular/core';
import { FormBuilder, Validators, ReactiveFormsModule } from '@angular/forms';
import {
  NxInput,
  NxCheckbox,
  NxButton,
  NxValidators,
  TextValueAccessor,
  BooleanValueAccessor
} from '@_nx/stencil-library/angular';

@Component({
  selector: 'app-login-form',
  standalone: true,
  imports: [
    ReactiveFormsModule,
    NxInput,
    NxCheckbox,
    NxButton,
    TextValueAccessor,
    BooleanValueAccessor
  ],
  template: `
    <form [formGroup]="loginForm" (ngSubmit)="onSubmit()">
      <nx-input
        formControlName="email"
        label="Email Address"
        type="email"
        placeholder="user@example.com"
        errorText="Please enter a valid email address"
        [required]="true">
      </nx-input>

      <nx-input
        formControlName="password"
        label="Password"
        type="password"
        errorText="Password must be at least 8 characters"
        [required]="true">
      </nx-input>

      <nx-checkbox formControlName="rememberMe" color="primary" label="Remember me">
      </nx-checkbox>

      <nx-button type="submit" color="primary" fill="solid" [disabled]="loginForm.invalid">
        Log In
      </nx-button>
    </form>
  `
})
export class LoginFormComponent {
  private fb = inject(FormBuilder);

  loginForm = this.fb.group({
    email: ['', [Validators.required, Validators.email]],
    password: ['', [Validators.required, Validators.minLength(8)]],
    rememberMe: [false, [NxValidators.requiredTrue]]
  });

  onSubmit() {
    if (this.loginForm.valid) {
      console.log('Form data:', this.loginForm.value);
    }
  }
}
```

> **Tip**: In standalone components using forms, you can also spread `...NX_VALUE_ACCESSORS` (or import `NxComponentLibraryModule`) instead of listing individual value accessors.
